# Infrastructure Inventory — gods-eye-view (`integration/ondemand-native`)

Scope: every runtime, build, CI and external component this checkout depends on, plus the Vercel project
`ondemand-eand-spatial` (team `schoolhack-web-team`) it deploys to and the sibling checkout
`../ondemand-eand-spatial`. Every claim is cited to `file:line` in this checkout (verified by reading the file
on 2026-10-20), to the Vercel/OnDemand facts the orchestrator verified live the same day, or to a dated doc.
No secret values appear in this document — only variable **names**.

Target state (see §7): **a single AI gateway = OnDemand**. Every inference path that does not go through
`/api/ondemand/*` is classified BYPASS and is scheduled for removal.

Legend — decision column: **KEEP** (stays as-is), **CONSOLIDATE** (stays but is merged / ported / made durable),
**REMOVE** (delete, archive or decommission).

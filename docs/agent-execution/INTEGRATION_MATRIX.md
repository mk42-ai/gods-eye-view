### Capabilities UNSUPPORTED by OnDemand (Keep-Direct Rationale)
The remaining external integration call sites cannot and should not be wrapped into OnDemand conversational tools:
1. **Persistent AIS Live WebSocket Relay (`/api/ais-live`):** Connects to `wss://stream.aisstream.io` with a rolling memory cache. A continuous duplex socket relaying hundreds of binary position messages per second cannot be represented as a stateless HTTP tool call. Keyless/stateless access is handled via `vessels_in_bbox`.
2. **Browser Map Tiles, Basemaps & 3D Tiles:**
   - Cesium ion terrain & Bing imagery (`ion.cesium.com`)
   - Google Photorealistic 3D Tiles (`tile.googleapis.com`)
   - Esri ArcGIS World Imagery tiles (`services.arcgisonline.com`)
   - OpenStreetMap raster tiles (`tile.openstreetmap.org`)
   *Reason:* High-throughput binary 3D geometries and imagery tiles rendered directly by the client WebGL graphics pipeline. They are visual display surfaces, not queryable knowledge.
3. **CCTV Live Media & Video Streams (`/api/cctv/media/:id`, `/api/cctv/frame/:id`, Google Street View static):** Binary image buffers (JPEG) and video streams (HLS/MJPEG/MP4) requiring media decoders, incompatible with JSON data envelope standards. Camera metadata is fully supported via `cameras_in_bbox`.
4. **External Typography & CDN Assets (Google Fonts):** Static styling assets loaded via `<link>` in `index.html`.
5. **Operational Infrastructure & Tooling:**
   - Vercel KV / Upstash Redis (`kv-store.js`): Durable storage / deduplication cache.
   - Vercel Deployments API (`scripts/vercel-file-deploy.mjs`): Build and release orchestration.
   - Offline build scripts (`scripts/build-sf-neighborhoods.mjs`, `scripts/refresh-celestrak-snapshot.mjs`).

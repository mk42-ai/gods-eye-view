# Gods-Eye component spec (one page)

All components live under `src/gods-eye/ui/`, read only `tokens.css`, mount lazily (nothing is in
the DOM until a scene exists) and expose stable ids/data-attributes (the Playwright suite in
`tests/e2e` asserts on them). Every file ≤ ~250 lines; keyboard: Tab through cards/pins/timeline/
routes, Enter plays, Esc closes; visible focus rings; AA contrast (see DESIGN_TOKENS.md).

| component | module | DOM | shows at | content / behaviour |
|---|---|---|---|---|
| **Header** | `ui/scene/header.js` | `#ge-scene-header[data-kind][data-stage][data-route-fallback][data-live-status]` | S2 | name, coords `25.1470°N 55.1990°E`, kind badge, `UAE Interest Watch`, `tRefLabel` (`estimated 14:32 GST ±10 min` / `reported 2026-09-26`), AOI name, `ROUTE: NN%` or amber `ROUTE: FALLBACK`, `N sources · M clips`, nearest source distance, live status dot |
| **Footage rail** | `ui/scene/rail.js` (+`railFormat.js`) | `#ge-rail > ol > li.ge-card[data-item-id][data-platform][data-recency][data-confidence]` | S4 | virtualised (88 px rows, viewport ± 6); thumbnail, platform icon, avatar/initial, `@handle`, `0.8 km from target`, `+14 min after incident` / `posted 2 h ago`, confidence chip (exact/inferred/unknown), recency badge, `SRC` link; hover ↔ pin pulse; ArrowUp/Down, Enter = play |
| **Timeline** | `ui/scene/timeline.js` | `#ge-timeline`, `input#ge-timeline-scrub`, `.ge-tl-tick[data-item-id]`, `.ge-tl-alert[data-alert-id]`, `.ge-tl-band[data-recency]`, `#ge-timeline-play`, `#ge-timeline-reset` | S4 | tRef at T0, clip ticks, alert markers, LIVE/RECENT/ARCHIVE bands; scrub = 15-min window filtering pins + cards; PLAY = chronological playlist |
| **Player** | `ui/scene/player.js` (+`playerResolve.js`) | `#ge-player[data-playing][data-kind][data-item-id]`, `#ge-banner`, `.ge-player-overlay`, `#ge-player-pip` | poster from S0; media only on S4 arrival | YouTube iframe (autoplay, mute, enablejsapi), TikTok `/embed/v2`, Instagram `/embed/`, direct MP4 `<video muted autoplay playsinline>`; distance/time overlay; persistent `REBUILT FROM ARCHIVAL FOOTAGE — originally reported <date>` for rebuild scenes; `arm()` for zero-network restores (poster + overlay, press Play/Enter); Document-PiP or draggable mini |
| **Evidence strip** | `ui/scene/evidence.js` | `#ge-evidence span.ge-ev[data-platform][data-status]` | S2 | `YOUTUBE OK 20`, `TIKTOK QUOTA`, `X INACTIVE` … |
| **Map layers** | `ui/scene/mapLayers.js` (+`mapLayersGraphics.js`) | Cesium entities `ge:<sceneId>:pin:*`, `:ring:*`, `:leader:*`, `:dist:*`, `:route:*`, `:aoi`, `:cluster:*` | pins S2, clusters/leader lines S3, AOI ring S0–S1 | pin colour = recency; confidence ring solid / dashed / greyed fan; leader lines; 0.5/1/2 km rings; ground routes coloured by status (open/restricted/closed/unknown) with hover label; cluster > 8 within 100 px; `clear(sceneId)` removes exactly one scene |
| **Posters** | `ui/scene/posters.js` + `public/assets/states/state-*.png` | `img.ge-player-poster` | — | live-acquiring (idle/fetching), flyin-building (loading/flying), no-footage, archive-rebuild, source-quota, source-inactive-error, route-fallback, outside-aoi, saved-recreate-diff — exposed as `--ge-poster-*` tokens |
| **Scenes panel** | `ui/scenes-panel/{index,card}.js` | `#ge-scenes` in the existing `#scene-panel`; tabs `#ge-scenes-tab-active/-archive/-legacy`; `article.ge-scene-card[data-scene-id][data-kind][data-new][data-archived]`; `.ge-scene-diff` | always (panel is collapsed by default) | cards: title (inline rename), kind, NEW/ARCHIVED, target, tRef, clip count, nearest distance, 3 thumbnails, top platform icon, route chip; Open / Recreate / Rename / Duplicate / Delete / Share; intercepts the existing `#scene-start-btn/#scene-next-btn/#scene-stop-btn` → time-ordered playback with 4.2 s + 11 s dwells; `#ge-scenes-status` |
| **Sources sidebar** | `ui/sidebar/index.js` | `#ge-sources-toggle`, `#ge-sources-panel li.ge-source[data-platform][data-status]` | always (collapsed) | rows TikTok, Instagram, YouTube, X, Reddit, Web, Route Monitoring Agent: icon, on/off checkbox (persisted `godsEye.sources`), status pill OK/QUOTA/INACTIVE/ERROR/IDLE, count, latency; replaces the HUD CAPABILITIES tab visually |
| **Register modal** | `ui/sidebar/registerModal.js` | `#ge-register-modal[role=dialog]`, `#ge-reg-name/-lat/-lon/-country`, `select#ge-reg-category`, `#ge-reg-accept/-decline` | outside-register prompt | "Add site to register?" with outside-register poster; decline = build nothing, fetch nothing |

Orchestration: `src/gods-eye/orchestrator.js` (install + `window.__godsEye`), `build.js` (prompt →
geocode → register → route → fly → fetch → rank → play; Open; Recreate + diff), `playback.js`
(START/NEXT/STOP), `diff.js`. Backend: `api/footage/{index,route,scenes_store,fixtures_replay}.py`.
